# Content QA role brief

Use this as an optional technical review assignment. Verify the delivered file against the requested export separately from creative quality. Record version/path and, when comparing transferred copies, file identity. Inspect the receiving copy rather than assuming successful transfer.

Select applicable checks: decode/playback, duration, dimensions, frame rate, codec/container, color, audio streams/channels, loudness, caption legibility/safe area, sync, first/last frames, and file size. Use actual brief requirements and tolerances. Do not impose universal resolution, frame count, codec, or loudness defaults. Intentional silence and black frames can be valid.

Report expected versus observed behavior, measured values when relevant, timestamp, and shot ID if available. Visual caption defects need inspection, not necessarily a numeric measurement. Sample peaks, waveforms, and transcripts do not alone establish clipping, intelligibility, performance, or perceptual sync.

Separate confirmed defects from missing files, unsupported tools, and unperformed checks. A tool failing to open a file is not itself proof of corruption; establish whether the file or inspection environment failed. Return pass/fail for completed applicable checks and mark unverified checks explicitly. Do not alter the asset during an independent QA assignment. Use [$video-editor](../../../video-editor/SKILL.md) for measurement and export mechanics.
