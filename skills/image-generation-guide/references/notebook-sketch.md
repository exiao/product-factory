# Notebook sketch style

Use this original shared style block for the default notebook look; change it only for user-requested variations:

```text
Hand-drawn sketch on a warm off-white cream page with a faint light-gray dot grid (bullet-journal style, dots ~5mm apart). Drawn with a fine-point felt-tip fineliner, monoline ~0.4mm. Lines are clean and controlled but with a subtle human wobble — confident, not shaky, not vector-perfect. Exactly two ink colors: matte black for line work and a vibrant royal blue for accents and labels. Outline-only rendering: NO shading, NO gradients, NO drop shadows; at most a few short-stroke hatch marks for texture where it reads naturally. Lettering is extremely neat legible print handwriting (sans-serif feel), consistent height: large spaced-out UPPERCASE for the title, tidy mixed-case for labels and notes. Labels connect to parts with thin single-stroke lead lines. Emphasis via simple single-stroke hand underlines. Generous margins, ample whitespace, composition aligned to the dot grid. Flat top-down scan of a notebook page, even lighting, no photo perspective.
```

## Choose a layout

- **Single object:** center the subject in outline with an uppercase title; add only useful short callouts.
- **Labeled study:** place labels in generous margins with thin leaders that clearly reach the intended parts.
- **Before/after:** use two aligned columns with comparable subjects and an explicit short takeaway. A left-black/right-blue comparison is an available variation of the two-ink style.
- **UI or process:** use simplified low-fidelity phones or shapes, consistent scale, clear directional relationships, and only essential quoted screen text. Decorative status-bar details need not be readable.

Keep the title and captions short, quote all text that must appear, and maintain generous whitespace. Outline-only is the default; tiny stars or checkmarks can be filled if needed for clarity. Do not add a third ink color, gradients, or heavy shading unless the user asks to change the style. Simplify crowded labels before attempting another generation of the same overcrowded prompt.
