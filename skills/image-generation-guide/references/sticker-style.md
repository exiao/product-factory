# Die-cut stickers and sticker-style cards

Use this treatment when requested; it is not the default for all social graphics. Generate or edit with the built-in image tool following the parent guide, and save the verified file locally.

## Choose the artifact

A **standalone sticker** has a visible die-cut border and transparent exterior; the colored interior belongs to the artwork and must remain opaque. A **sticker-style card** uses the border, rounded silhouette, bold type, and restrained shadow inside an opaque canvas. Do not strip the background of a social card unless asked.

Choose the size and aspect ratio for the intended use. A square canvas is a reasonable starting point for an unspecified social card, not a mandatory export size. For print production, obtain the printer's actual dimensions, bleed, and cut-line requirements; an attractive PNG alone is not a verified print-ready file.

## Visual brief

Keep a clean rounded silhouette, a thick white die-cut border proportionate to the artwork, generous internal padding, bold readable type, and a restrained shadow when desired. The default card sits upright and square without perspective skew; honor a request for a tilted or irregular sticker. Use exact supplied brand colors and official marks. The original navy/cyan Bloom treatment is a historical example, not a brand to add to unrelated work. No automatic Bloom wordmark.

For a generic card without supplied colors, a dark navy interior with white type and one cyan accent is an available starting direction. Adapt it to the actual brief. Avoid incidental decoration that weakens the headline or key value.

### Announcement card

```text
Create an upright sticker-style card, large rounded corners, thick white die-cut border, restrained soft shadow. [Opaque background / transparent exterior around the sticker].
Palette: [colors].
Headline: "[exact text]", large bold type with generous padding.
Supporting line or key value: "[exact text]".
Optional short callout: "[exact text]".
Keep a clear hierarchy and readable text at the intended display size. No unrequested logo or extra copy.
```

### Data or earnings card

Use the same silhouette. Place the supplied ticker and time period first, then a small number of verified values, with units and labels kept together. Add an optional concise watch item. Transcribe and verify all values from the supplied evidence; the image model does not invent estimates or report financial results. Use a deterministic text layer when exact editable data density exceeds what a generated image can reliably carry, within the user's requested format and current tool rules.

### Logo sticker

Use the exact provided mark with a surrounding die-cut silhouette and clear padding. Preserve the official logo rather than replacing it with generated lettering. A request to create a new logo is separate from making a sticker of an existing one.

## Check the final

Inspect the full-resolution image and its intended small display size: exact words and values, border continuity, padding, orientation, branding, and crop. For a transparent sticker, verify actual alpha, preserved opaque interior, and clean edges against light and dark backgrounds. Deliver the final checked cutout, not the earlier opaque render. Use focused built-in edits for corrections and preserve the good source before iterating. Do not install a background-removal model or silently change providers.
