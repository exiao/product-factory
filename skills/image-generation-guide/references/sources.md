# Sources and limits

This guide consolidates the user's existing Hermes imagegen-cli prompting playbook, nano-banana-pro skill, Higgsfield still-reference and product-photoshoot guidance, thumbnail workflow, and installed Codex character-creation, notebook-sketch, storyboards, design-mode, and imagegen guidance. Provider commands, fixed model choices, prices, backend-only prompt enhancement, and automatic external uploads were intentionally excluded from the portable method.

- [@twoclipping image realism post](https://x.com/twoclipping/status/2090040350706745697): original author's full 679-character post retrieved through Bird search on 2026-09-08; its entire eight-line detail block is included in the realism reference. It has four attached example images. A broader search returned five other users' replies; full `thread --all` failed with HTTP 401. This is not a complete conversation or a local archive of the example images. Some retrieved replies criticized the outputs as visibly generated and pointed to background geometry errors, reinforcing whole-image inspection.
- [@abxxai character thread](https://x.com/abxxai/status/2094819241916801165): eight tutorial posts retrieved with Bird and matched exactly against the existing local archive on 2026-09-08. The source contains duplicate female tennis still prompts, omits the field woman's still-edit prompt, changes female identity between scenes, and ends the tennis video prompt mid-sentence. The reusable still-image editing principles are paraphrased in this guide; source errors are not defaults to reproduce.

The original playbook records older generation comparisons, but one purported A/B also changed lighting and camera anchors. They are historical observations, not controlled proof of model-independent improvement. This guide's installation did not rerun those generations. Validate each actual output and use genuinely controlled comparisons when needed.
