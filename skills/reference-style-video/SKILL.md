# Reference-style video

Measure before describing. Obtain the supplied reference or an authorized local copy, then inspect geometry, duration, cut timestamps, cuts per minute, locations, framing, caption placement, caption color, transitions, motion, sound, and the first two seconds. Use a contact sheet and sampled frames. Never characterize the style from thumbnails, memory, or transcript alone.

Turn measurements into a beat sheet with one row per cut or distinct edit event: time, shot/framing, spoken or on-screen text, caption treatment, motion/transition, overlays, and audio. Summarize three to five signature moves that can be applied to the user's own footage and message. Match the rhythm and grammar, not the reference's exact script, footage, music, brand marks, or distinctive creative expression.

Build the new edit from the beat sheet, then measure it the same way. Compare cuts per minute, shot variety, caption readability, placement, and pacing. Report measured matches and remaining gaps plainly. This skill analyzes and directs; use [$video-script](../video-script/SKILL.md) for scripting and [$video-editor](../video-editor/SKILL.md) for local ffmpeg operations. It does not download from a platform, publish, or purchase media unless explicitly requested and the required local/network capability is available.

Read [references/measure-a-reference.md](references/measure-a-reference.md) for reproducible probes and [references/edit-anatomy.md](references/edit-anatomy.md) for the beat-sheet method. For animated typed captions, read [references/typed-captions.md](references/typed-captions.md).
