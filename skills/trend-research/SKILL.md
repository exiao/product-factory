# Ongoing editorial trend discovery

Use this skill to identify patterns worth watching or adapting, not to answer one bounded “what happened in the last 30 days?” question. Select platforms based on the user's audience and decision. A sensible default is one real-time conversation source, one high-intent video/source, and one niche or professional source; do not scan every platform by habit.

Check which connectors, APIs, browser tools, or local CLIs are actually available before using them. Current platform pages and provider schemas change. If a source requires login or is unavailable, use an accessible source, state the gap, and do not infer absence from a shell page, blocked response, or empty result.

For each item capture only fields the source exposes: title/hook, caption or transcript excerpt, creator, platform, direct URL, published time, views/reach, likes, comments, shares/reposts, saves/bookmarks, creator audience, format, sound/audio, category, and ranking. Keep raw source output before parsing when the tool returns structured data that may be difficult to reproduce.

Rank within each platform before comparing across platforms. Use relative signals such as engagement rate, views per hour, creator-size breakout ratio, saves/bookmarks for repeatable formats, and cross-platform recurrence. A weighted virality score is a comparison aid, not a universal truth; do not let YouTube views drown out smaller-platform evidence. Treat one platform's high performer as an opportunity until another source confirms the pattern.

Read [references/triangulation-and-parsing.md](references/triangulation-and-parsing.md) for platform caveats, raw-first workflow, source-status reporting, and synthesis rules. Finish with cross-platform signals, notable single-source opportunities, format/hook anatomy, what to avoid, and a small set of remixable briefs. Do not publish, schedule, or create an automation unless the user separately requests that workflow.
