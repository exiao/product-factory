# Revision prescriptions

Use the smallest diagnosis that explains the problem. Preserve the author's facts, certainty, point of view, and emotional temperature.

| Observable pattern | Prescription | Example |
|---|---|---|
| Abstract claim with no evidence | Add the observed mechanism, output, or source, or mark `[NEEDS SOURCE]`. | "It works well" → "The evaluator traced 35 of 36 claims to raw files." Only use the count if the source supplies it. |
| Mannered metaphor | Restate it literally, then keep the metaphor only if it explains a mechanism. | "The launch opened a new chapter for onboarding" → "The launch changed onboarding." |
| Buried lede | Remove setup until the first sentence states what happened. | Start with the observed failure or result, then explain context. |
| Restated trailer | Delete the second sentence when it adds no fact, constraint, consequence, or action. | "Collect the decisions you made. Use real numbers." → "Collect the decisions you made, with real numbers." |
| Unfalsifiable hedge | Cut the hedge or replace it with the evidence boundary. | "In many ways, faster" → "The measured run took 40 minutes." |
| Passive sentence with a missing actor | Name who or what acted. | "Queries are validated" → "The evaluator validates queries." |

## Prosody pass

Read the draft aloud. Check where breath, emphasis, and speed change.

- Join related clauses with commas when every sentence has become a clipped command.
- Vary paragraph and sentence length without smoothing away a deliberate aside or unusual phrase.
- Put the important noun or verb near the end of a sentence only when the cadence earns the emphasis.
- Remove punctuation used only to manufacture suspense, including em dashes and dramatic colon reveals.
- Keep a pause when it changes meaning. Delete a pause that only announces that the previous sentence mattered.

## Show-don't-tell moves

| Tell | Show |
|---|---|
| "The workflow is reliable." | "The same fixture ran through the parser, evaluator, and report, and the report recorded the same verdict." |
| "The page feels clearer." | "The heading states the outcome, the primary action sits beside it, and the old duplicate label is gone." |
| "The model made a mistake." | "It named a field that the current schema does not contain; the failing query is in the trace." |

These are pattern examples. Replace every result, field, and artifact with observed evidence before publishing.
