# Scene schema

For a full production script, use a global header and the applicable fields for each scene:

```markdown
# Title
Platform: TikTok | Reels | Shorts | YouTube
Aspect: 9:16 | 16:9 | 1:1 | 4:5
Duration: target
Style: talking-head | explainer | demo | montage | narrative
Audience and promise: ...

## SC01 - purpose [0:00-0:03, estimated]
Required visual beat: what viewers must see to understand the scene
Source: concrete stock search, screen capture, supplied asset, or generation brief
Spoken copy:
- SC01-L01 [speaker/narrator]: exact line
Delivery intent: tone or emphasis when relevant
Caption text: exact words, if needed
Other audio intent: music, SFX, or silence when story-relevant
Story continuity: facts, actions, or emotional changes carried to the next scene

### Shots (only when direction is requested)
SC01-SH01: references SC01-L01; direction adds camera, lighting, action,
duration, visual continuity, and production details here.
```

Keep stable scene IDs, and stable line IDs when shots need to reference spoken copy. Store authoritative dialogue and narration only in the scene section. Direction may add several shots under one scene; do not create a second script or renumber existing IDs merely because a shot is inserted. Identify affected shots after authorized copy or timing changes. Separate required visual beats from how they will be filmed. Label claims that need research and never hide missing source material behind vague “B-roll” placeholders.
