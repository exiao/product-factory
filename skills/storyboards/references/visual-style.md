# Editable storyboard style profile

Edit the defaults below to change this skill's starting visual direction. A task's explicit style, references, or calling animation brief override these defaults. This profile controls appearance, not the panel story or narrative structure.

| Setting | Editable default |
| --- | --- |
| Art direction / preset | Inherit the task or animation's art direction. If none exists, choose a treatment that makes its action and payoff easy to see. No fixed preset. |
| Medium / rendering | Inherit supplied references; otherwise choose illustration, collage, photography, 3D, or another suitable treatment. |
| Palette | Follow the selected direction; no fixed ink count or required accent color. |
| Linework / shading | Follow the medium; outlines, fills, lighting, and shadows are all available. |
| Background / texture | Follow the setting and direction; no required paper or dot grid. |
| Typography / captions | Legible at review size. Use exact supplied copy and keep labels subordinate to the action. Handwriting is optional. |
| Framing / aspect ratio | Match the intended animation or deliverable when supplied. |
| Panel layout | Fit the chosen beat count and reading order. Use strips, grids, or separate frames as appropriate. |
| Recurring subjects / references | Preserve supplied identities and meaningful props across panels. |

For example, changing Art direction to "cinematic clay miniature" and Palette to "warm ochre and deep teal" establishes those defaults without changing the story. Set Art direction to "notebook" to select the optional [notebook preset](notebook-style.md); any edited settings above still override its details.

Include the chosen settings with the delivered board so the user can request changes to the medium, palette, texture, type, or composition directly. A style revision should preserve the agreed story unless the user also asks to change it.
